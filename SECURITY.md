# Security Policy

## Reporting a vulnerability

Please do not publish security-sensitive details in a public issue.

For a vulnerability involving this project, contact the repository owner privately through GitHub and include:

- affected version or commit;
- affected component;
- reproduction steps;
- impact;
- any suggested mitigation.

Remove passwords, private keys, ADB credentials, tokens and personal network information from reports.

## Scope

This project is a community GUI around CleanYourTV and Android TV tooling. Security reports are especially useful for issues involving unsafe command execution, path traversal, unintended package changes, credential exposure or malicious repository content.
