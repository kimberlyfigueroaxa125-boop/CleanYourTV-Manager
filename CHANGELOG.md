# Changelog

All notable changes to CleanYourTV Manager will be documented here.

## Unreleased

### Added

- Qt Designer XML desktop interface.
- ADB connection and Android TV diagnostics.
- CleanYourTV project discovery through `CLEANYOURTV_ROOT`.
- Local theme and add-on inventory.
- Timestamped local project backups.
- PyInstaller specification that bundles the Qt `.ui` file.
- Windows CI with linting, tests and executable packaging.

### Safety

- No Android package is disabled automatically.
- TV input and Live TV functionality is treated as protected functionality.
